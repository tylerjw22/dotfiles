# Hyprland Dotfiles

My personal **Hyprland dotfiles** for a minimal, customizable Linux desktop.

## Contents

* Hyprland configuration
* Waybar
* Wofi
* Kitty
* Fish
* Neofetch
* Other desktop settings and scripts

## Installation

Clone the repository and copy the desired configuration files into your `~/.config` directory.

> **Note:** These are my personal configurations, so you may need to modify paths, packages, and settings for your own system.
